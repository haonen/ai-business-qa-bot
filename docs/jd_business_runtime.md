# 京东品牌生意分析 Runtime

## 触发

用户同时明确京东/JD、品牌、时间，并询问生意分析、品牌生意、
GMV复盘或GMV与品类表现时，路由到`jd_business_analysis`。缺少时间时
进入`clarify_jd_period`。

推荐问法：

> 请做【品牌】在【时间段】的京东自营生意分析，输出品牌整体GMV、同比和三级类目表现。

京东大盘/Top 5仍走大盘分析；京东媒体花费仍走BET媒体分析。

## 数据源

- 报告数值统一使用`jd_store_ranking_selfrun_day_jiashicang`。
- 月表`three_platform_store_rank_monthly`可用`platform='JD'`校验品牌是否存在，
  但该表没有`category_level_3`，不参与本报告数值计算。
- 完整月和非完整月都从同一京东自营日表汇总，确保品牌总GMV
  与三级类目GMV加总完全一致。

两张表使用`bus_date`、`brand_name`、`gmv`和`category_level_3`。GMV原始单位为
人民币元，品牌口径为京东自营旗舰店。

## 计算

- 本期与同期都使用同一品牌、全品类和数据源选择逻辑。
- 同期为去年相同自然日期。
- 品牌总GMV由所有三级类目GMV加总得到；空类目记为“未分类”。
- 品类占比 = 品类GMV / 品牌全品类GMV。
- GMV同比 = 本期GMV / 同期GMV - 1。
- 占比变化 = 本期占比 - 同期占比，按pp展示。
- 报告展示本期GMV前6个三级类目，其余类目按原始值合并为“其他”。
- 所有指标先用未四舍五入原始值计算，只在格式化阶段转换为M、%和pp。

## 输出约束

- 报告标题固定为“京东品牌生意分析”。
- 不展示内部数据表、字段或查询口径说明。
- 不展示Top商品链接或商品级分析。
- 同比统一显示为`+44%`、`-44%`或`0%`，不输出`0.44`。
- 占比变化为零时显示`0pp`，不显示`-0pp`。
