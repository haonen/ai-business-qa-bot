# Skill：Key Driver分析

## 适用场景
用户追问李佳琦、T2、Non-KOL、自播、达人等渠道的贡献、占比、增速或渠道迁移。

## 必须调用的工具
1. query_driver
2. query_kol（仅作情报通直播口径参考）
3. query_sku_list（必要时查看渠道Top链接）

## 分析步骤
1. 同时呈现最大贡献渠道和增长最快渠道。
2. 增长最快渠道需排除2026 GMV占比低于2%的小渠道。
3. 情报通数据必须标注“直播口径参考”，不得与主GMV数据直接相加或比较。
4. ATV只用于生意质检，不用于渠道定位叙事。

## 结论生成三层结构（通用框架）
L1 现状：渠道GMV、unit、atv和占比来自query_driver。
L2 变化：同比、占比变化和增长贡献来自query_driver。
L3 打法信号：仅当渠道占比年度迁移超过narrative_config.json阈值时生成，并使用“呈现/侧重/聚焦/集中”等白名单措辞。

## 数据边界
只能使用工具返回的数据生成结论。禁止提大盘、行业、竞品和未提供的人群画像。
